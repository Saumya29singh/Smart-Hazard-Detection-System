# 🚧 Smart Hazard Detection System

A Full Stack MERN web application that enables users to report, track, and manage road hazards efficiently. The platform helps improve public safety by allowing citizens to submit hazard reports while providing administrators with tools to monitor and resolve reported issues.

## 🚀 Features

* 📝 Report road hazards with detailed information
* 📍 Location-based hazard reporting
* 📊 Track complaint status in real time
* 👨‍💼 Admin dashboard for complaint management
* 🔒 Secure user authentication
* 📱 Responsive and user-friendly interface

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/Smart-Hazard-Detection-System.git
```

### Navigate to the project

```bash
cd Smart-Hazard-Detection-System
```

### Install dependencies

**Frontend**

```bash
cd client
npm install
```

**Backend**

```bash
cd ../server
npm install
```

### Configure Environment Variables

Create a `.env` file inside the `server` folder.

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### Run the project

**Backend**

```bash
npm run server
```

**Frontend**

```bash
npm start
```
